# Product Overview

Mastodon is a free, open-source decentralized social network server built on the ActivityPub protocol. It enables users to create federated communities where users on different servers can seamlessly communicate, breaking free from vendor lock-in.

## Core Capabilities

- **Federated Social Networking**: Interoperable with any ActivityPub-compliant software, enabling cross-platform communication in the Fediverse
- **Real-time Content Sharing**: Chronological timeline updates with support for text, images, videos, and polls
- **Moderation & Safety**: Private posts, locked accounts, content filtering, muting, blocking, and comprehensive reporting/moderation system
- **OAuth2 API**: REST and Streaming APIs enabling a rich third-party app ecosystem
- **Multi-tenancy**: Self-hosted instances with customizable rules, branding, and registration policies

## Target Use Cases

- **Community Self-Hosting**: Organizations and communities running their own social network instances
- **Federation Participation**: Joining the broader Fediverse network while maintaining control
- **Alternative Social Media**: Privacy-focused alternative to centralized platforms
- **API Integration**: Building custom apps and clients using the comprehensive API

## Value Proposition

- **Freedom & Control**: Open-source (AGPLv3), self-hosted, no vendor lock-in
- **Decentralization**: Part of the larger federated Fediverse network
- **Privacy & Safety**: User-controlled privacy settings with robust moderation tools
- **Extensibility**: Rich API supporting diverse client applications and integrations
